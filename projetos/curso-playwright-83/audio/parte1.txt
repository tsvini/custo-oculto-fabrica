Última aula. Vamos deixar o seu projeto pronto pra quem visitar. Cria um README ponto md com: o objetivo, as tecnologias, o que precisa instalar, como instalar, e os comandos pra rodar os testes. Coloca o selinho do GitHub Actions. O próprio GitHub gera o código dele, com o endereço do seu repositório e do seu workflow. Ele mostra se os testes estão passando. E a sua colinha completa: do primeiro comando ao Page Object, ao login salvo, ao GitHub Actions e à API. E a página cinco, com o nível dois inteiro. São cinco páginas: deixa ela aberta enquanto pratica. Você começou sem saber nada e terminou com dois projetos: o primeiro, com login, compra, API e tudo rodando no GitHub. E o segundo, que começou num card: os cenários, o bug achado na mão, e a automação que garante que ele não volta. Próximos passos: pratique, crie novos cenários e mantenha o seu GitHub atualizado. E se o curso te ajudou, deixa uma avaliação honesta na Udemy. Ela ajuda a melhorar o curso e orienta outros alunos. Até a próxima!
