A tarefa mudou: o usuário precisa conseguir anexar um documento. Currículo, comprovante, planilha. No the internet, a tela é a File Upload. Na página inicial, clica nela. Na tela tem um botão Choose File, escolher arquivo, que abre a janela do computador pra procurar o arquivo. E o botão Upload, que envia. Depois de enviar, a página mostra o nome do arquivo. O teste vai fazer igual: escolher um arquivo, clicar em Upload, e conferir que o nome dele apareceu. Mas pra enviar um arquivo, o teste precisa ter um arquivo. Na pasta do projeto, cria uma pasta nova chamada arquivos. E dentro dela, um arquivo de texto: exemplo ponto txt. Dentro, qualquer texto. Esse é o arquivo que o teste vai enviar. No internet ponto spec, um teste novo: upload de arquivo. Primeiro, o goto da tela de upload. E o campo, no Inspecionar: um input do tipo file, com id igual file upload. E o botão Upload tem o id file submit. Agora a ação nova: o campo file upload, ponto set input files, e entre parênteses o caminho do arquivo: arquivos barra exemplo ponto txt. Traduzindo: set input files, coloque este arquivo no campo. E o caminho começa na pasta do projeto: a pasta arquivos, e o exemplo ponto txt. Repara: o Playwright não abre aquela janela do Windows pra procurar o arquivo com o mouse. Ele entrega o arquivo direto pro campo. Depois, clica no botão Upload. E confere: a área uploaded files, onde o nome aparece, contém o texto exemplo ponto txt. Roda: escolheu, enviou, e o nome apareceu. ⟨pausa:2.5⟩ No dia a dia, também vale testar o lado ruim: um arquivo grande demais, ou de um formato que o sistema não aceita.
