O Git é um programa que guarda versões do seu projeto. Como pontos de salvamento num jogo. No terminal do VS Code: git init. Init é iniciar: comece a guardar as versões desta pasta. Depois: git add ponto. Add é adicionar, e o ponto quer dizer tudo: prepare todos os arquivos pro próximo salvamento. Repara que o node modules, o ponto env e a pasta do login salvo não entram: o gitignore está fazendo o trabalho dele. E: git commit traço m, e uma mensagem entre aspas, tipo meu primeiro projeto Playwright. Commit é o salvamento, e o traço m é a mensagem dele. Se for a primeira vez que você usa o Git, ele pode pedir seu nome e seu e-mail. São dois comandos: git config traço traço global user ponto name, e user ponto email. Depois roda o commit de novo. Pronto: o seu projeto tem o primeiro ponto de salvamento. Na próxima aula, ele vai pro GitHub. Te vejo lá!
