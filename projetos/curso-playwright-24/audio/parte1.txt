Aqui no saucedemo o usuário e a senha são públicos. Mas em projeto de verdade, senha e chave escrita no código é um problema: quando o projeto for pro GitHub, todo mundo vê. Então a gente vai aprender o jeito usado em projetos reais: um arquivo chamado ponto env, que guarda essas informações fora do código. Primeiro, instala o pacote que lê esse arquivo. No terminal: npm install traço D dotenv. O traço D marca como ferramenta de desenvolvimento do projeto. Na pasta do projeto, cria o arquivo ponto env. Dentro: SAUCE underline USER igual standard user, e SAUCE underline PASSWORD igual secret sauce. E antes de qualquer outra coisa: abre o ponto gitignore e escreve ponto env no final. Assim esse arquivo nunca vai pro GitHub. No config, tira o comentário daquelas três linhas do dotenv. Elas mandam ler o arquivo ponto env. No teste, troca o texto por process ponto env ponto SAUCE underline USER. Traduzindo: process ponto env, as variáveis do ambiente. SAUCE underline USER, a variável com esse nome. E pra quem baixar o projeto saber o que preencher, cria um ponto env ponto example só com os nomes das variáveis, sem os valores. Roda pra confirmar: continua passando.
