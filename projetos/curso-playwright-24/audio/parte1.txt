Aqui no saucedemo o usuário e a senha são públicos. Mas em projeto de verdade, senha e chave escrita no código é um problema: quando o projeto for pro GitHub, todo mundo vê. Então a gente vai aprender o jeito usado em projetos reais: um arquivo chamado ponto env, que guarda essas informações fora do código. A ideia é simples. O ponto env fica só no seu computador. O teste não tem mais a senha escrita: ele pede pro ponto env. E cada pessoa do time coloca o próprio usuário e a própria senha no ponto env dela. Pra ler esse arquivo, a gente usa um pacote chamado dotenv. Pacote é um código pronto que alguém já escreveu e que você baixa pro seu projeto. No terminal: npm install traço D dotenv. Install quer dizer instalar. E o traço D marca como ferramenta de desenvolvimento do projeto. Na pasta do projeto, cria o arquivo ponto env. Dentro: SAUCE underline USER igual standard user, e SAUCE underline PASSWORD igual secret sauce. E antes de qualquer outra coisa: o ponto gitignore. Ignore é ignorar: é a lista de arquivos que o Git deixa de fora quando você manda o projeto pro GitHub. Escreve ponto env no final dele. Agora o config. Lá em cima já tem três linhas do dotenv, só que comentadas: com as duas barras na frente, o Playwright ignora. Apaga as duas barras das três linhas. Lendo em português: importe o dotenv, importe o path, que cuida dos caminhos das pastas, e leia o arquivo ponto env que está nesta pasta. No teste, onde estava escrito standard user, troca por process ponto env ponto SAUCE underline USER. E a senha, por process ponto env ponto SAUCE underline PASSWORD. No segundo teste, o usuário bloqueado continua escrito, porque ele é o que o teste quer testar. Só a senha vem do ponto env. Traduzindo: process ponto env, as variáveis do ambiente. SAUCE underline USER, a variável com esse nome. Quando o teste roda, o dotenv já leu o arquivo, e aqui entra o standard user. E pra quem baixar o projeto saber o que preencher, cria um ponto env ponto example só com os nomes das variáveis, sem os valores. Roda pra confirmar: continua passando.
