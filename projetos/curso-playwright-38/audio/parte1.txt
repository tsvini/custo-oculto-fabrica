Cria uma pasta nova chamada pages, e dentro o arquivo LoginPage ponto js. Primeira linha: export class LoginPage, e abre chaves. Traduzindo: class é um molde, uma receita pra criar objetos. LoginPage é o nome do molde. E export deixa outros arquivos usarem. Dentro, o constructor, que recebe o page. Constructor quer dizer construtor: é o que roda quando alguém cria um LoginPage. Primeira linha dele: this ponto page igual page. This quer dizer este: guarde o page dentro deste LoginPage. Agora os elementos da página, um por linha: this ponto usuario igual page ponto get by test id username. Guarde o campo usuário com o nome usuario. Mesma coisa pra senha, o botão e a mensagem de erro. E aqui está o ganho: se um dia o data-test do botão mudar, você troca só nesta linha, e todos os testes que usam o LoginPage continuam funcionando. Por enquanto, ele só sabe onde estão as coisas. Na próxima aula, ele aprende a fazer o login, e o teste passa a usar. Te vejo lá!
