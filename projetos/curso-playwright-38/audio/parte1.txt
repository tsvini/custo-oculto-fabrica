Primeiro, cria uma pasta nova chamada pêidjis. Pages quer dizer páginas: é aqui que vão ficar os arquivos de cada página do site. E dentro da pasta pêidjis, um arquivo novo: Lóguin Pêidji ponto jota éssi. A página do login. Primeira linha: export class Lóguin Pêidji, e abre chaves. Traduzindo: class é um molde, uma receita pra criar objetos. Lóguin Pêidji é o nome do molde. E export deixa outros arquivos usarem. Dentro, o constructor, que recebe o page. Constructor quer dizer construtor: é o que roda quando alguém cria um Lóguin Pêidji. Primeira linha dele: this ponto page igual page. This quer dizer este: guarde o page dentro deste Lóguin Pêidji. Agora os elementos da página, um por linha: this ponto usuario igual page ponto get by test id username. Guarde o campo usuário com o nome usuario. Mesma coisa pra senha, o botão e a mensagem de erro. E aqui está o ganho: se um dia o data-test do botão mudar, você troca só nesta linha, e todos os testes que usam o Lóguin Pêidji continuam funcionando. Por enquanto, ele só sabe onde estão as coisas. Na próxima aula, ele aprende a fazer o login, e o teste passa a usar. Te vejo lá!
