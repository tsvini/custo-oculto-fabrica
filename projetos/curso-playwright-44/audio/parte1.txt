O GitHub é um site que guarda projetos Git na internet. É a vitrine de quem trabalha com tecnologia. Cria uma conta no github ponto com, se ainda não tiver. Depois clica em New repository, dá o nome e cria, sem marcar nenhuma opção. O GitHub mostra os comandos. No terminal: git branch traço M main. Dá o nome main pro ramo principal. Depois: git remote add origin, e o endereço do seu repositório. Remote é remoto: avise o Git que existe uma cópia lá no GitHub, chamada origin. E o envio: git push traço u origin main. Push é empurrar: mande o projeto pro GitHub. O traço u liga a sua main com a main de lá, e nas próximas vezes basta git push. Na primeira vez, o Git pode abrir o navegador pra você entrar na sua conta do GitHub. É normal: faz o login e volta pro terminal. Atualiza a página do GitHub: seu projeto está lá. E repara: nem o ponto env, nem a pasta do login salvo subiram. Na próxima aula: os testes rodando sozinhos no GitHub. Te vejo lá!
