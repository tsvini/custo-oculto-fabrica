O GitHub é um site que guarda projetos Git na internet. É a vitrine de quem trabalha com tecnologia. Pra você, ele resolve três coisas: um backup do projeto, se o computador quebrar. Um lugar onde a equipe trabalha junto. E o seu portfólio: quem for te contratar pode ver o seu código funcionando. Cria uma conta no github ponto com, se ainda não tiver. Depois clica em New repository. Repositório é a pasta do projeto, lá no GitHub. Dá o nome e cria, sem marcar nenhuma opção, porque o seu projeto já tem os arquivos dele. O GitHub mostra os comandos. No terminal: git branch traço M main. Branch é ramo: uma linha de versões do projeto. Esse comando dá o nome main pro ramo principal. Depois: git remote add origin, e o endereço do seu repositório. Remote é remoto: avise o Git que existe uma cópia lá no GitHub, chamada origin. E o envio: git push traço u origin main. Push é empurrar: mande o projeto pro GitHub. O traço u liga a sua main com a main de lá, e nas próximas vezes basta git push. Na primeira vez, o Git pode abrir o navegador pra você entrar na sua conta do GitHub. É normal: faz o login e volta pro terminal. Atualiza a página do GitHub: seu projeto está lá. E repara: nem o ponto env, nem a pasta do login salvo subiram. E daqui pra frente, o ciclo é sempre esse: add, commit e push. E o GitHub fica igual à sua máquina. Na próxima aula: os testes rodando sozinhos no GitHub. Te vejo lá!
