Hoje a gente mexe no arquivo de configuração. Parece assustador, mas são só duas linhas. Abre o playwright ponto config ponto js e procura o use. Use quer dizer: use isso em todos os testes. Tira o comentário da baseURL e coloca o endereço do saucedemo. Base URL: o endereço base. Agora, no teste, o goto fica só com uma barra. O Playwright junta essa barra com o endereço base. A vantagem: se um dia o site mudar de endereço, você troca num lugar só. Segunda linha: test id attribute igual data-test. Lembra do data-test que a gente viu no Inspecionar? Por padrão, o get by test id procura data-testid. O saucedemo usa data-test. Essa linha avisa o Playwright. Agora o get by test id também funciona no saucedemo. Pra você ver esse outro caminho, a gente vai trocar os seletores que já estão nos testes. Repara: o before each continua igual, ele só abre o site. A troca é assim: onde estava get by placeholder Username, fica get by test id username. A senha vira password. E o botão vira login button. No primeiro teste, as três linhas do login trocadas. E no segundo teste, a mesma troca. Os seletores antigos também estavam certos: é só outro caminho pro mesmo lugar. Traduzindo: ache pela etiqueta de teste chamada username.
