# Roteiros aprovados · Boas-vindas + Módulo 1 (v2, com ajustes da revisão)
Regra geral: nenhuma aula abre com "Fala, pessoal". Abertura vai direto ao assunto.

## Aula 1 · O que você vai construir
1. Seja muito bem-vindo ao Playwright para Leigos. Eu sou o Vinícius. [título]
2. Antes de qualquer explicação, eu quero te mostrar onde você vai chegar. [bigtext]
3. Isso aqui é o projeto final do curso: um robô que entra numa loja de verdade, faz login, coloca produto no carrinho e finaliza a compra, sozinho. [pw_ui]
4. E o mesmo teste roda no Chromium, no Firefox, no WebKit, que é o motor por trás do Safari, e até simulando um celular. [pw_relatorio]
5. Quando alguma coisa quebra, o Playwright mostra exatamente onde, com foto de cada passo. [pw_trace]
6. E no final, você vai colocar tudo no GitHub, e os testes vão rodar sozinhos toda vez que você mudar o código. Esse verde aqui é o seu projeto funcionando sem você encostar em nada. [gh_actions]
7. E o melhor: isso tudo vai pro seu portfólio. É um projeto que você pode mostrar numa entrevista. [cards]
8. E você não vai copiar um projeto pronto. A gente vai construir tudo junto, do zero. [bigtext]
9. Se você nunca programou, relaxa. Eu vou explicar cada linha, e você vai ver sempre o código inteiro na tela, não só um pedaço. [bigtext]
10. Na próxima aula, eu te mostro como aproveitar melhor o curso, e te entrego a sua colinha. [passo]
11. Te vejo lá! [endcard]

## Aula 3 · Instalando o VS Code
1. Primeira instalação: o VS Code, o programa onde a gente vai escrever os testes. [título]
2. O VS Code é um editor de código. Pensa num bloco de notas turbinado, que pinta cada parte do código de uma cor e te ajuda a não errar. [compare]
3. É gratuito, é da Microsoft, e é um dos editores mais usados no desenvolvimento de software. Você vai encontrar ele em muitas empresas. [cards]
4. Primeiro passo: abre o navegador e entra em code ponto visualstudio ponto com. Clica no botão Download for Windows. [tela]
5. Segundo passo: abre o arquivo que baixou, na pasta Downloads. [pastas]
6. Aceita o contrato e clica em Next. [instalador]
7. Nessa tela, marca o Add to PATH e as duas opções Open with Code. Isso facilita muito a vida depois. [instalador]
8. Clica em Install, espera, e no final clica em Finish. [instalador]
9. Pronto! Esse é o VS Code. Na esquerda ficam os arquivos do projeto, e no meio é onde você escreve. [editor]
10. Na próxima aula, a gente instala o Node, que é o motor que faz o Playwright funcionar. [passo]
11. Te vejo lá! [endcard]

## Aula 4 · Instalando o Node.js
1. Agora é a vez do Node.js. [título]
2. O Playwright é escrito em JavaScript, e o Node é o programa que roda JavaScript no seu computador. Sem ele, o Playwright não liga. [flow]
3. Junto com o Node vem o npm, que é tipo uma loja de aplicativos pra programador. É por ele que a gente vai instalar o Playwright. [cards]
4. Entra em nodejs ponto org e baixa a versão que tem escrito LTS. LTS é a versão estável, a que menos dá dor de cabeça. [tela]
5. Abre o instalador e vai clicando em Next. Pode deixar todas as opções como vierem. [instalador]
6. Clica em Install. Se o Windows pedir permissão, clica em Sim. [instalador]
7. Agora vamos conferir. Aperta a tecla do Windows, digita PowerShell e abre. [iniciar]
8. Essa é a janela do terminal. É só um lugar onde você escreve comandos em vez de clicar. [terminal]
9. Digita node traço v e aperta Enter. Depois, npm traço v e Enter. [terminal]
10. Apareceu um número em cada um? Mesmo que diferente do meu, está tudo certo. [bigtext]
11. Na próxima aula, a última instalação: o Git. [passo]
12. Te vejo lá! [endcard]

## Aula 5 · Instalando o Git
1. Última instalação: o Git. [título]
2. O Git guarda o histórico do seu projeto, como os pontos de salvamento de um videogame. Deu problema? Volta pro último ponto salvo. [cards]
3. E é com ele que, no fim do curso, o seu projeto vai pro GitHub e passa a rodar os testes sozinho. [gh_actions]
4. Entra em git traço scm ponto com, clica em Download for Windows e baixa a versão recomendada para o seu Windows. [tela]
5. O instalador tem bastante tela, mas dá pra deixar quase tudo no padrão e ir clicando em Next. [instalador]
6. Só uma tela merece atenção: quando ele perguntar o editor, escolhe o Visual Studio Code. [instalador]
7. Clica em Install, espera, e Finish. [instalador]
8. Pra conferir, abre o PowerShell e digita git traço traço version. [terminal]
9. Apareceu a versão? Então você tem tudo: o VS Code, o Node e o Git. [cards]
10. Se o seu computador é Windows, pode pular a próxima aula, que é de Mac e Linux, e ir direto pro módulo dois. [passo]
11. Te vejo lá! [endcard]

## Aula 6 · Instalando no Mac e no Linux
1. Essa aula é pra quem usa Mac ou Linux. Se você usa Windows, pode pular. [título]
2. São os mesmos três programas: o VS Code, o Node e o Git. Só muda o jeito de instalar. [cards]
3. No Mac, pra abrir o terminal, aperta Command e espaço, digita Terminal e aperta Enter. [passo]
4. O VS Code: baixa em code ponto visualstudio ponto com, abre o arquivo e arrasta pra pasta Aplicativos. [instalador]
5. O Node: em nodejs ponto org, baixa a versão LTS pra Mac e vai clicando em continuar. [instalador]
6. O Git é o mais fácil: digita git traço traço version no terminal. Se não tiver, o próprio Mac oferece instalar. [terminal]
7. Agora o Linux. Eu vou mostrar no Ubuntu. O terminal abre com Control, Alt e T. [passo]
8. O VS Code se instala com sudo snap install code traço traço classic. O sudo pede a sua senha do computador, e enquanto você digita não aparece nada. É normal. [terminal]
9. O Git, com sudo apt install git. [terminal]
10. O Node, no Ubuntu, a gente instala com uma ferramenta chamada nvm, porque o que vem pelo apt costuma ser antigo. São três comandos, e eles estão aqui na tela e na descrição da aula. [terminal: curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.40.8/install.sh | bash · \. "$HOME/.nvm/nvm.sh" · nvm install --lts]
11. E tem um detalhe que é só do Linux. Quando a gente instalar o Playwright, ele vai pedir umas bibliotecas do sistema. Lá na hora, eu te mostro o comando que resolve. [cards]
12. Pra conferir: node traço v, npm traço v e git traço traço version. [terminal]
13. Todos os comandos estão na descrição da aula. Até o módulo dois! [endcard]

## Aula 7 · Se der erro na instalação, consulte aqui
1. Se tudo funcionou até aqui, você pode pular esta aula e seguir pro módulo dois. Volta aqui se tiver algum problema. [título]
2. Erro um: o terminal diz que node, npm ou npx não é reconhecido. Quase sempre o terminal foi aberto antes de instalar o Node. [terminal]
3. A solução: fecha o terminal e o VS Code e abre de novo. Se continuar, reinicia o computador. [cards]
4. Erro dois, só no Windows: a execução de scripts foi desabilitada neste sistema. É uma trava de segurança do PowerShell. [terminal]
5. Na maioria dos computadores, resolve rodando esse comando uma vez, que está aqui na tela. Depois fecha e abre o terminal. Se o computador for da empresa, pode ser que a TI bloqueie essa mudança, e aí vale falar com eles. [terminal: Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser]
6. Erro três, esse já é do Playwright: aparece executable doesn't exist, o executável não existe. Quer dizer que faltam os navegadores dele. [terminal]
7. Resolve com npx playwright install. Ele baixa o Chromium, o Firefox e o WebKit. No Linux, acrescenta traço traço with traço deps, que instala as bibliotecas do sistema junto. [terminal]
8. Erro quatro: ele diz que não acha nenhum teste, ou nenhum arquivo de configuração. É o terminal aberto na pasta errada. Olha o caminho antes do cursor: tem que terminar com o nome da pasta do projeto. [terminal]
9. E a dica de ouro: copia a mensagem de erro e cola no Google. Alguém já passou por isso. Programador experiente faz isso todo dia. [bigtext]
10. Volta aqui sempre que precisar. Até a próxima! [endcard]
