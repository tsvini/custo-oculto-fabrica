Política de privacidade

Atualizada em 19/10/2026

O aplicativo "Custo Oculto Fabrica" é uma ferramenta interna usada apenas pelo próprio canal Custo Oculto para publicar os seus vídeos nas suas próprias contas do Instagram, Facebook e TikTok.

Dados que usamos

Usamos somente os tokens de acesso das nossas próprias contas, concedidos por nós mesmos, e os dados básicos dessas contas (identificador, nome de usuário, contagem de seguidores e de publicações) para confirmar que a publicação funcionou.

Dados que não coletamos

O aplicativo não coleta, armazena, vende nem compartilha dados de outros usuários, seguidores ou visitantes. Não há cadastro de terceiros.

Armazenamento

Os tokens ficam guardados como segredos criptografados no GitHub Actions e podem ser revogados a qualquer momento nas configurações da Meta ou do TikTok.

Exclusão de dados

Como não guardamos dados de terceiros, não há nada a excluir. Para qualquer pedido, escreva para tsvini10@gmail.com e respondemos em até 30 dias.

Privacy policy (English)

"Custo Oculto Fabrica" is an internal tool used only by the Custo Oculto channel to publish its own videos to its own Instagram, Facebook and TikTok accounts. It only uses access tokens for our own accounts and basic account data (id, username, follower and post counts). It does not collect, store, sell or share data from any other user. Tokens are stored as encrypted GitHub Actions secrets and can be revoked at any time. Data deletion requests: tsvini10@gmail.com.
