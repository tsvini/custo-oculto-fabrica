# Testes automatizados com Cypress

Projeto final do curso **Cypress para Leigos**.

Testes E2E da loja de treino [Sauce Demo](https://www.saucedemo.com):

- **login**: sucesso, usuário bloqueado, senha errada e campos vazios
- **carrinho**: adicionar e remover produto
- **loja**: ordenar por preço e sair da conta
- **compra completa**: com um e com dois produtos

## Como rodar

Precisa ter o [Node.js](https://nodejs.org) instalado (aula 3).

```
npm install
npm test
```

Para ver os testes rodando na janela do Cypress:

```
npm run abrir
```
